# Recorded Klebsiella workflow

See [the worked example](../../docs/beta/WORKED_EXAMPLE.md) and
[Mac commands](../../docs/mac-klebsiella-walkthrough.md).

`recorded-results.json` summarises named local executions. Large provider caches,
assemblies, matrices and generated reports are not included. These are recorded
results, not a runnable input fixture. The separate `examples/beta` three-record
synthetic fixture runs prepare/cgmlst/viewer export without credentials.

The local review entry page is `tmp/beta-worked-example/index.html`. It links
existing results without copying large data. Human usability has not been tested;
two independent agent reviews are explicitly labelled simulated checks.
