# Country, region, city and host summaries

The cgMLST report summarises the combined input and public comparison dataset
before showing genetic relationships. Country is shown throughout; region, city
and host controls appear when those fields contain data. Missing values remain
Unknown. Counts describe the retrieved sequenced records, not prevalence.

The interactive state-change network can use country, region, city or host.
It reconstructs changes on the analysis tree; it does not establish direct
transmission or country of acquisition. See the [report guide](report.md) and
[cgMLST workflow](cgmlst.md) for analysis and downloadable outputs.
