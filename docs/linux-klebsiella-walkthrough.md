# Klebsiella assemblies on Linux x86_64 and Slurm

Start with declared local assemblies and species, let preparation call classical
ST and cgMLST, inspect public-context costs, then analyse and select genomes for
parallel tree/time runs. LIN assignments are optional in default profile mode.
The smaller historical provider-profile smoke test is recorded at the end.

## Install tools and the native reference

```bash
pixi install --frozen
pixi install --frozen -e mlst
pixi run --frozen chronoclade preflight --stage all
pixi run --frozen chronoclade setup-typing --species klebsiella --prepare-db \
  --destination /shared/chronoclade/klebsiella-typing
```

Replace `/shared/chronoclade` with a writable path visible to login and compute
nodes. Setup needs `uv`; see [query typing](query-typing.md). Native executables
must run on the compute nodes. Keep the setup directory and its content hashes.

The public historical cgMLST reference can become ready while the separate LIN
reference remains unavailable. Current LIN reference builds need their own
upstream authorization; a Pathogenwatch download key does not supply it. Normal
preparation can use the validated caller-only reference without LIN. Preserve
the setup receipt's actual allele-access cutoff and reference identity; a
retrieval-date version does not imply comprehensive current allele coverage.

Configure existing protected Pathogenwatch access as described in
[installation](installation.md#pathogenwatch-credentials). Credentials must be
available on the relevant compute nodes and stay outside command lines, input
CSVs and committed files. The classical `mlst` environment is separate from the
Pathogenwatch native cgMLST caller.

## Declare a small public assembly cohort

For a reproducible test, the ST218 candidate pool was small enough to inspect
completely. Three QC-pass public genomes have distinct verified dates and
countries:

| Run accession | BioSample | Collection date | Country |
| --- | --- | --- | --- |
| ERR2586402 | SAMEA4668447 | 2011-05-05 | Vietnam |
| SRR5973402 | SAMN07525404 | 2017-02-16 | United States |
| ERR10438022 | SAMEA111504607 | 2020-03-10 | Ghana |

This is a test cohort chosen for metadata and workflow coverage, not an unbiased
surveillance sample or a claim that these isolates are epidemiologically linked.
Same ST alone does not establish a close genomic relationship.

The following uses the existing public metadata and checked assembly-download
helpers to obtain starting inputs. It does not construct typing intermediates:

```bash
mkdir -p klebsiella-linux
pixi run --frozen python - <<'PY'
import csv
from pathlib import Path
from chronoclade.pathogenwatch import PathogenwatchClient, deduplicate_catalogue
from chronoclade.profile_inputs import materialise_assemblies

root = Path("klebsiella-linux").resolve()
client = PathogenwatchClient()
catalogue = client.freeze_catalogue(root / "public-metadata.json", organism_id="573", st="218")
rows, _ = deduplicate_catalogue(catalogue["rows"])
ids = ["7oYHYmZoyyq6Q5ndQa2hqy", "cm5CfFDUg9mG5j5XyL3AgG", "dZfePqBBSqwaWSZP1wwyxd"]
chosen = [next(row for row in rows if row["source_genome_id"] == ident) for ident in ids]
assert all(row["qc_pass"] for row in chosen)
samples = materialise_assemblies(chosen, output=root / "input-acquisition", client=client)
assemblies = {sample.sample_id: sample.assembly.resolve() for sample in samples}
fields = ["sample_id", "label", "assembly", "species", "collection_date", "country",
          "host", "isolation_source", "runAccession", "sampleAccession"]
with (root / "assemblies.csv").open("w", newline="") as handle:
    writer = csv.DictWriter(handle, fieldnames=fields)
    writer.writeheader()
    for row in chosen:
        accession = row["run_accessions"][0]
        writer.writerow({**{key: row.get(key) or "" for key in fields},
                         "assembly": str(assemblies[row["sample_id"]]), "label": accession,
                         "runAccession": accession, "sampleAccession": row["biosample"]})
PY
```

The source metadata/download ledger retains provider identities and checksum
receipts. The initial CSV deliberately omits ST, cgMLST typing and the provider
UUID: otherwise provider-profile prefetch can satisfy typing before the native
caller is exercised. Verified run/BioSample aliases remain available for public
input-identity exclusion. Scientific typing is generated by preparation.

## Prepare assemblies concurrently

```bash
pixi run --frozen chronoclade slurm-prepare klebsiella-linux/assemblies.csv \
  --typing-config /shared/chronoclade/klebsiella-typing/query_config.json \
  --out klebsiella-linux/prepare-jobs --results klebsiella-linux/prepared \
  --account YOUR_ACCOUNT --partition YOUR_PARTITION \
  --cpus 1 --memory-gb 4 --max-parallel 3 --walltime 00:30:00
bash klebsiella-linux/prepare-jobs/submit.sh
```

Each task prepares one exact input assembly. The dependent collector publishes
the complete original cohort after successful tasks; it does not publish a
reduced input set when a task fails. Check `squeue`, task/collector logs and the
saved plan. See [Slurm execution and recovery](independent-suite.md#local-and-slurm-jobs).

Inspect `prepared/report.html` and `readiness.json`. All intended inputs need
usable native profiles; missing classical ST affects public discovery separately.
Unassigned LIN labels do not make a usable profile unavailable. Missing/novel
calls, absent references or credentials remain explicit. Keep the input list and
assembly identities rather than silently replacing failed genomes.

## Inspect public-context cost before retrieving profiles

```bash
pixi run --frozen chronoclade cgmlst klebsiella-linux/prepared/dataset.json \
  --context-preflight --context-max-candidates 300 \
  --out klebsiella-linux/context-plan
```

Open `context-plan/index.html` and download its JSON evidence. This count-only
step previews every pool without retrieving genome details or profile exports.
It reports source-record counts before sample deduplication, export-batch
estimates and an upper bound for one float64 guide-distance matrix before
deduplication. This is not a peak-memory estimate: other matrices and working
arrays add costs.

An oversized pool makes the plan exit with status 2; it does not truncate the
pool. A context budget of ten controls the later assembly selection, not public
retrieval. Deliberately change the candidate guard or choose local analysis if a
complete public pool is too large. Current public counts may differ from the
recorded ST218 snapshot of 146 source records and 92 sample units.

## Select mandatory and optional context genomes

```bash
pixi run --frozen chronoclade cgmlst klebsiella-linux/prepared/dataset.json \
  --fetch-context \
  --typing-config /shared/chronoclade/klebsiella-typing/query_config.json \
  --context-max-candidates 300 --context-size 10 --subsamples 3 \
  --representative-reserve 3 --seed 5 --bootstrap-replicates 0 \
  --out klebsiella-linux/cgmlst
```

The complete eligible public profile pool supplies the guide analysis. Native
and public profiles must have verified scheme/locus and allele correspondence;
do not relabel incompatible allele numbers to force a comparison. Public
input identities are excluded through verified aliases.

Open `cgmlst/index.html` and its block report. Every original input and all
mandatory nearest-neighbour ties must be present in every saved selection.
The representative reserve requests optional context beyond required neighbours;
the ten-context budget can expand explicitly to preserve both. Check actual
mandatory/optional counts, the selection CSVs, distinct alternatives and overlap.
Three requested sets are not automatically three distinct sets: limited pools
or tied obligations can make alternatives identical. Do not weaken nearest
retention or identity checks merely to manufacture variation.

Metadata stratum quotas are fixed across an ensemble; representative identity
varies within those quotas. If the chosen quota cells contain only one eligible
genome each, alternatives can duplicate despite a large overall pool. The
initial ST218 test with seed 42 encountered that condition. Seed 5 was selected
from metadata/stratum eligibility before SNP inference or dating, to exercise
within-stratum alternatives. This changes the declared sampling seed, not the
nearest-neighbour obligations or dating gate.

Metadata capture and profile retrieval preserve checked progress. If interrupted,
repeat the original analysis command with `--resume` and the same inputs/options.
Completed checked pages/details are reused; a partial catalogue is not published
as complete. See [context planning and retrieval](cgmlst.md).

## Run selected trees and time analyses in parallel

Replace `BLOCK` with the block listed in the guide report:

```bash
pixi run --frozen chronoclade slurm-ensemble tree \
  klebsiella-linux/cgmlst/BLOCK/selection_bundle/ensemble.json \
  --out klebsiella-linux/tree-jobs --results klebsiella-linux/tree \
  --account YOUR_ACCOUNT --partition YOUR_PARTITION \
  --cpus 4 --memory-gb 8 --max-parallel 3 --walltime 01:00:00
bash klebsiella-linux/tree-jobs/submit.sh
```

After collection completes, inspect the tree ensemble and each temporal
assessment. Then run the normal time stage, preserving its scientific gate:

```bash
pixi run --frozen chronoclade slurm-ensemble time \
  klebsiella-linux/tree/tree_ensemble.json \
  --out klebsiella-linux/time-jobs --results klebsiella-linux/time \
  --account YOUR_ACCOUNT --partition YOUR_PARTITION \
  --cpus 1 --memory-gb 8 --max-parallel 3
bash klebsiella-linux/time-jobs/submit.sh
```

An unsupported temporal assessment is a valid completed outcome. Do not override
it to obtain a dated tree. Review the comparison report and distinguish
within-run conditional uncertainty from between-selection sensitivity. Inspect
interactive trees, ordinations and networks, and verify actual offline downloads.

## Recorded native assembly-first validation

On 18 October 2026, native setup completed in 4m50s. The three declared
assemblies resolved to ST218 and 628/629 cgMLST loci each. A one-CPU-per-task
preparation array completed in 21s from first worker start to collector end
(17s workers, 3s collector and a 1s dispatch gap), compared with 47s for one serial run; queue time and reference setup are excluded.
The parallel route used up to three CPUs and each task requested 4GiB. Exact
profiles, metadata, assembly hashes and sample order matched the serial result.
For these same three genomes, an independent allele-DNA comparison against
provider profiles found zero discordances at 628 jointly called loci each.
This does not retype all public context assemblies.

The fresh validation chain retrieved 146 raw ST218 records, normalized to 92
sample units, then excluded all three inputs from context. Its guide contains
three inputs and 89 public comparisons. Seed 5 produced three distinct selections,
each with all three inputs, eight mandatory neighbours and three optional
representatives. Requested context budget 10 became effective budget 11 because
of the representative reserve. Browser checks verified the complete 92-genome
NJ guide and ordination, interactive network controls, PNG/HTML exports and
actual offline manifest/Newick downloads. Worker evidence is retained and linked
from the collector report. All three selected 14-tip SNP trees completed 100
date permutations and passed post-recombination coherence screening. Their
observed rates were negative, so all three normal time results were unsupported
without an override. The comparison report preserves that valid outcome.
Actual offline stage Newick/JSON downloads and all three selected-tree figure
viewers were browser-checked. A later presentation-only fix adds explicitly
labelled mandatory cgMLST-guide stars and hides empty nearest-neighbour legends;
it was verified against a separate rendering of the saved 14-tip data without
rewriting checksummed scientific outputs.

The final software validation passed 1,220/1,220 tests across eight Slurm shards
and a strict documentation build. Actual browser acceptance passed 47 distinct
grouped checks, excluding repeated runs.

The final evidence is under
`validation/performance-followup-20261018/klebsiella/final/` (gitignored).
Count-only preflight and an independent interrupted-metadata recovery test are
retained alongside it. `--resume` reuses checked interrupted work; a fully
completed guide is immutable and refuses another run into that directory.

## Recorded historical provider-profile smoke test

The earlier Linux x86_64 run on 18 October 2026 started from a bounded public
search page of 12 ST147 records and existing provider typing. Explicit LIN5
partitioning produced blocks of 1, 2, 8 and 1 genomes. The eight-genome block
completed two overlapping tree tasks and two time tasks. All genomes were inputs
and both selections were identical. This demonstrated native inference and
scheduler execution, not native assembly cgMLST calling, public-context selection
variation or speedup against a serial benchmark.

The tools were SKA2 0.5.1, IQ-TREE 2.4.0, ClonalFrameML 1.20, TreeTime 0.12.1 and
RapidNJ 2.3.3. Tree tasks requested four CPUs/8 GiB, took 127 and 126 seconds and
shared eight verified cached assemblies. Time tasks took 24 seconds each with
one CPU/8 GiB. Both trees completed 100 date permutations; empirical p = 5/101
was close to the configured 0.05 threshold. This is workflow evidence, not
biological validation of the cohort.

Historical local evidence is `validation/linux-x64-20261018/` (gitignored).
Keep that earlier result separate from the native assembly-first route above.
