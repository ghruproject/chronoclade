# Input data

ChronoClade accepts collections, accessions, assemblies or frozen profiles through
`prepare`. The saved `dataset.json` is the handoff to the cgMLST stage. For
assemblies, provide an explicit species and configure the compatible typing
caller and reference database. Preparation records readiness and provenance;
public context discovery happens later in cgMLST.

See [input preparation](prepare.md) for supported formats and requirements, and
the [independent workflow](independent-suite.md) for complete commands.

Use the most precise verified collection date available. Keep patient-level data
and unpublished assemblies out of public repositories. Missing metadata remains
explicit in reports and evidence.
